# nRF Bridge Protocol

This document describes the binary frame codec shared by the Python host bridge
and the Phase 1B receive-only nRF52840 firmware.

## Frame Format

All frames are little-endian and have the following shape:

```
magic(2) | version(1) | type(1) | flags(1) | seq(1) | length(2) | payload | crc32(4)
```

- `magic`: `VW` (0x56 0x57)
- `version`: 1
- `type`: Enum (see Frame Types)
- `flags`: Reserved
- `seq`: Sequence number
- `length`: Length of payload in bytes
- `payload`: Variable length
- `crc32`: Standard CRC-32 (IEEE 802.3) of the header and payload combined

## Frame Types

- `HELLO` (0x01)
- `HELLO_RESP` (0x02)
- `RX_FRAME` (0x03)
- `TX_RAW` (0x04) - **Reserved. TX is not implemented or enabled in Phase 1.**
- `STATE` (0x05)
- `ERROR` (0x06)
- `GET_STATS` (0x07)
- `GET_STATS_RESP` (0x08)

## RX_FRAME Payload

The `RX_FRAME` payload has the following shape:

```
timestamp_us(8) | channel(1) | rssi_dbm(1) | lqi(1) | raw_psdu(N)
```

- `timestamp_us`: 64-bit unsigned integer
- `channel`: 8-bit unsigned integer
- `rssi_dbm`: 8-bit signed integer
- `lqi`: 8-bit signed integer
- `raw_psdu`: Remainder of payload

The host implementation is `gateway/radio/nrf_bridge_proto.py`; the firmware
implementation is `firmware/nrf_vwg_bridge_rx/src/bridge_proto.c`.

## HELLO_RESP Payload

The Phase 1B firmware emits a `HELLO_RESP` frame after USB CDC ACM is opened.
The current payload is ASCII capability text:

```text
proto=1;name=nrf_vwg_bridge_rx;fw=0.1.0;cap=RX_ONLY
```

## ACK Separation

It is critical to distinguish between three types of ACKs:

1. **Transport ACK**: Handled by the serial protocol (e.g. sequence numbers).
2. **MAC ACK**: Handled by the IEEE 802.15.4 layer (not visible in `raw_psdu` unless promiscuous).
3. **Vendor ACK**: The Viconics `cmd=3` application-level ACK, generated by the thermostat and emitted as an `OtaAckEvent`.

## Transmit Restrictions

Active transmission (`TX_RAW`) is **not implemented** in Phase 1A/1B. The bridge acts as a passive sniffer only to ensure safety and prevent disruption to the live PAN.
